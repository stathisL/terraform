
# Terraform Portfolio

A collection of Infrastructure as Code (IaC) projects built using Terraform, initially focused on AWS cloud infrastructure.

The repository showcases practical implementations of cloud infrastructure provisioning, networking, security, automation, and deployment using Terraform.

## Repository Structure

Projects are organized into separate directories, each representing an independent infrastructure implementation.

```text
terraform/
|-- 01-aws-high-availability-web-infrastructure/
|-- 02-aws-static-website-hosting/
|-- 03-aws-container-cicd-pipeline/
|-- 04-aws-serverless-event-driven-app/
|-- README.md
```

## Project Organization

Each project is self-contained and independently deployable. It includes:

- Terraform configuration files for infrastructure provisioning.
- A dedicated `README.md` documenting the project architecture, implementation, and deployment instructions.
- An architecture diagram illustrating the infrastructure and its components.

Projects are designed to be deployed, managed, and destroyed independently, without dependencies on other projects in the repository.

## Project Goals

- Apply Infrastructure as Code principles using Terraform.
- Develop practical experience with AWS cloud services.
- Implement secure, scalable, and maintainable infrastructure.
- Explore infrastructure automation and CI/CD practices.
- Apply Terraform best practices, including modularity and environment separation where appropriate.

Additional projects and technologies may be introduced as the repository evolves.
